# 👧🚀 Girl in Space – A Python Arcade Game

A cute arcade-style game where you control a girl astronaut in space, collecting stars and dodging glowing asteroids! Built using Python and Turtle graphics, this game is simple, fun, and a great beginner-level game development project.

---

## 🎮 Features

- Collect stars to earn points
- Avoid glowing asteroids flying across the screen
- Smooth movement and simple controls
- Cute 50x50 character sprites
- Space-themed background music and sound effects

---

## 🛠️ Tech Stack

- **Language**: Python 3
- **Graphics**: Turtle Module
- **Audio**: Free game SFX from public domain sources
- **Assets**: Custom-generated and free-to-use
